# 📈 Stock Market Analysis Project

This project analyzes stock data using Python.

## 🔧 Tools Used
- Python
- Pandas
- Matplotlib
- yFinance

## 📊 Features
- Stock price visualization
- Moving averages (20-day, 50-day)
- Trend analysis

## ▶️ How to Run
1. Install libraries:
   pip install pandas matplotlib yfinance

2. Run:
   python stock_analysis.py
